期权，一个故事讲透

忘掉所有术语。我们就在一条街上，有房子、有保险公司、有赌场。
把四种玩法全走一遍，你就全懂了。

🏘️

整个期权世界，就是一条街上的四种人

这条街上有一套房子，现在市价 100 万。四种人围着这套房子，各怀心思。
买 Call 的人：花一点小钱锁定一个「涨了我能买」的权利——他是看涨的赌徒。
买 Put 的人：花一点小钱锁定一个「跌了我能卖」的权利——他是买保险的房东。
卖 Call 的人：收钱答应「涨了我以固定价卖给你」——他是限价挂单的房东。
卖 Put 的人：收钱答应「跌了我以固定价从你手里买」——他是保险公司。

买方付定金买「权利」，卖方收定金扛「义务」。这就是全部。

一、四种角色，四个故事

每种角色用一个生活场景讲透。下面的「定金」就是权利金，「行权价」就是约定好的价格。

买 Call：花小钱赌大涨买方 · 看涨
你看中一套房，怕明天涨价，但又拿不出全款。于是花 3 万定金锁定了一个月内 110 万买入的资格。
涨了？你赚差价。不涨？最多亏 3 万定金，不用真的买。
涨到 130 万 → 你 110 万买入转手卖 130 万，净赚 17 万
没涨过 110 万 → 不行权，只亏 3 万定金
最大亏损3 万（固定） 最大收益无上限 胜率较低
买 Put：给持仓买保险买方 · 看跌
你有一套 100 万的房子，怕暴跌。于是花 3 万保费买了个保险：一个月内不管跌多少，保底 90 万卖出。
跌了？保险兜底。不跌？保费白付，权当买个安心。
崩到 60 万 → 你照样 90 万卖，避免了 30 万损失，净省 27 万
没跌破 90 万 → 保险白买了，只亏 3 万保费
最大亏损3 万（固定） 最大收益87 万（跌到 0） 胜率较低
卖 Call：收租封顶上涨卖方 · 看不涨
你有房子，觉得一个月内涨不过 110 万。于是收别人 3 万定金，答应如果涨过 110 万就卖给他。
没涨过？3 万白赚。涨过了？只能 110 万卖，多涨的部分全归别人。
没涨过 110 万 → 房子还是你的，白赚 3 万
涨到 150 万 → 必须 110 万卖，少赚 37 万（裸卖则实亏）
最大收益3 万（固定） 最大亏损无上限（裸卖） 胜率较高
卖 Put：收保费等着接盘卖方 · 看不跌
你觉得这房子值钱，如果跌到 90 万你愿意接手。于是收别人 3 万保费，答应一个月内跌破 90 万就从他手里买走。
没跌破？3 万白赚。跌破了？你得按 90 万接货，可能浮亏。
没跌破 90 万 → 啥也不用做，白赚 3 万
崩到 60 万 → 必须 90 万买，浮亏 27 万
最大收益3 万（固定） 最大亏损87 万（跌到 0） 胜率较高
发现规律了吗？ 买方和卖方是镜像关系——买方付的定金，就是卖方收的定金；买方的收益曲线翻转 180° 就是卖方的。期权是零和游戏：一方赚的就是另一方亏的。

三、买方 vs 卖方：一张表看透

不用死记，抓住「买方花钱买权利，卖方收钱扛义务」这一条，其他全能推出来。

买方（付权利金）卖方（收权利金）
花钱 / 收钱先付出一笔固定的权利金先收到一笔固定的权利金
权利 / 义务有权利，没义务（可以不行权）有义务，没权利（对方要求就必须执行）
盈亏形状亏损封顶（就那点权利金），收益可以很大收益封顶（就那点权利金），亏损可以很大
胜率低。大部分期权到期作废高。时间站在卖方这边
时间是敌是友敌人。每过一天，你的权利在贬值朋友。每过一天，你的义务在消融
类比买彩票 / 买保险的人开彩票店 / 保险公司
最怕什么什么都没发生（钱白花了）黑天鹅（一次赔光前面所有利润）
适合什么人想用小钱博大的、或者要对冲的想稳定收租、愿意扛尾部风险的

四、时间这块冰，两边完全不同的感受

期权有「保质期」。同一块冰，在买方手里越融越亏，在卖方手里越融越赚。

花了 3 元买权利，冰块是满的

啥都没发生，冰融掉 1/4，权利金只值 2.3 了

还剩一个月
加速融化，权利金跌到 1.5

最后一周
断崖式融化！只值 0.4
0

冰完全融化 = 0。没有用到的权利一文不值
对买方：时间是你的敌人。你买了一张「保质期很短的优惠券」，每天都在贬值。所以买期权千万不要「拿着等」。

对卖方：时间是你的朋友。你收了钱等冰块融化就行，融完就全是你的。所以卖方的核心策略就是「等」。

这就是为什么有人说「买期权像创业（九死一生），卖期权像开银行（稳定收租但怕挤兑）」。

五、三个最重要的直觉

直觉 1 · 定价逻辑
权利金 ＝ 被行权的概率 × 平均赔付

跟保险公司算保费一模一样。「出事概率高」或「一出事赔得多」，保费就贵。
直觉 2 · 波动率的含义
波动率 ＝ 这套房子价格抖动的幅度

抖得越厉害，不管涨跌，期权都越贵。因为「可能发生大事」的概率在上升。
直觉 3 · 真正赚/亏钱的原因
买方赚钱靠方向 + 速度（猜对且猛）
卖方赚钱靠什么都没发生（静静等冰融化）

两种完全不同的交易哲学。

七、讲给朋友时最常被问到的问题

提前堵上这些问题，你的讲解就无懈可击了。

Q：买期权和直接买股票有什么区别？
买股票是花 100 万买一套房子；买 Call 是花 3 万买一张「一个月内能以 110 万买这房子」的券。猜对了，3 万撬动几十万收益（杠杆）；猜错了，最多亏 3 万（有底线）。代价是有期限、会归零。
Q：卖期权能亏多少？会倾家荡产吗？
裸卖 Call 理论上亏损无上限（股价可以涨到天上去），这就是为什么券商要求超高保证金。卖 Put 最多亏到股价归零。实际中用「价差」（同时买一个更远的做保护）可以把风险封死。
Q：为什么说「卖方胜率高」还能亏钱？
跟赌场的庄家一样——100 局里赢 92 局，每局赢 1 万；输那 8 局里有 1 局赔了 50 万。胜率高不等于赚钱，关键看「输的那次有多惨」。
Q：「备兑开仓」和「卖 Put」有什么关系？
持股 + 卖 Call ＝ 卖 Put。损益曲线形状完全一样。前者听起来安全（因为你有股票），后者听起来危险（因为叫「裸卖」），但数学上是同一件事。心理账户不同罢了。
